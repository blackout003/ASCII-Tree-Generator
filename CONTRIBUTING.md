# Guide de contribution 🚀

Un grand merci de l'intérêt que vous portez à ce projet ! Les contributions de la communauté sont ce qui rend l'open source si formidable.

Voici quelques règles simples pour que tout se passe au mieux.

---

## 📅 Comment ouvrir un ticket (Issue) ?

Avant de créer un ticket, veuillez vérifier dans l'onglet **Issues** que le problème ou la demande n'a pas déjà été signalé(e).

Si ce n'est pas le cas, vous pouvez ouvrir un ticket en utilisant l'un de nos modèles :
* **Rapport de bug :** Si quelque chose ne fonctionne pas comme prévu.
* **Demande de fonctionnalité :** Si vous avez une idée d'amélioration ou une nouveauté à proposer.

### 💡 Quelques règles de courtoisie :
- Un petit "Bonjour" ou "Merci" fait toujours plaisir et encourage la communauté.
- Soyez le plus précis possible (donnez des exemples de code, des captures d'écran, ou des messages d'erreur).

---

## 💻 Comment proposer une modification (Pull Request) ?

Si vous souhaitez modifier directement le code pour corriger un bug ou ajouter une fonctionnalité :

1. **Forkez** le projet sur votre compte GitHub.
2. Créez une branche descriptive pour vos modifications (`git checkout -b ma-nouvelle-fonctionnalite`).
3. Faites vos modifications en respectant le style de code existant.
4. **Commitez** vos changements avec des messages clairs.
5. **Poussez** (push) votre branche sur votre fork.
6. Ouvrez une **Pull Request** vers la branche principale du projet d'origine.

⚠️ **Rappel sur la Licence :** En contribuant à ce projet, vous acceptez que votre code soit soumis à la licence choisie pour le projet (ex: GPLv3). Vous serez bien sûr cité parmi les contributeurs !

---

Merci encore pour votre aide ! 🙌
